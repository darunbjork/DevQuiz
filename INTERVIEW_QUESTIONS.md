# DevQuiz Interview Questions

Here are 10 questions a teacher or recruiter might ask you about the DevQuiz project:

1.  Can you provide a high-level overview of this React application's architecture? How do users navigate between pages, and how is application state managed?
2.  I see you're using React's Context API for authentication (`AuthContext.tsx`). What are the benefits and drawbacks of this approach for a project like this?
3.  Could you explain the data flow when a user generates a new quiz? How do the `quizGenerator.ts` and `quizParser.ts` files work together?
4.  Why did you choose to use TypeScript in this project instead of JavaScript?
5.  This app uses `react-router-dom` for navigation. How did you implement protected routes to ensure only logged-in users can access specific pages?
6.  What was your reason for choosing Vite as the build tool for this project?
7.  What is your approach to testing? I see you're using Vitest; what kind of tests have you written for your components?
8.  I see you have components for charts like `AccuracyPieChart`. What role does data visualization play in this application?
9.  What were some of the challenges you faced when parsing the AI-generated text in the `quizParser.ts` file?
10. How did you decide to structure your UI into different reusable components inside the `src/components` folder?
